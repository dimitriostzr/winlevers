# Screenshots

Every view comes in a light and a dark version, taken from WinLevers 0.1.0 at
4250×2381 (a 2136×1196 window at 200% scaling). The README shows the one that
matches the reader's GitHub theme.

| View | Light | Dark | What it shows |

| Privacy advisor | [privacy-advisor-light.png](privacy-advisor-light.png) | [privacy-advisor-dark.png](privacy-advisor-dark.png) | The sensitive permissions, which apps hold each, and the deny buttons |
| App grid | [apps-grid-light.png](apps-grid-light.png) | [apps-grid-dark.png](apps-grid-dark.png) | The Microphone lens, filtered to the apps that are denied, rows tinted |
| GPU preference | [gpu-preference-light.png](gpu-preference-light.png) | [gpu-preference-dark.png](gpu-preference-dark.png) | The GPU power preference lens, with two apps set to Power saving |
| History | [history-light.png](history-light.png) | [history-dark.png](history-dark.png) | Past batches, each of which can be put back |
| Settings | [settings-light.png](settings-light.png) | [settings-dark.png](settings-dark.png) | Theme, table options, and where the journal, snapshots and logs are kept |

replaced with `user`; nothing else in any screenshot is edited.
